# Instrucciones para Claude

## Posts para redes sociales

Cuando se pida un post (Instagram u otra red), entregar siempre:

1. **Las imágenes listas para publicar**, no solo ideas de diseño:
   - Feed / carrusel: 1080×1350 px (una imagen por lámina).
   - Historia: 1080×1920 px, cuando aplique, con un espacio libre para el sticker de enlace.
   - Usar la marca del sitio: fondo oscuro `#1b2420`, dorado `#e8b04a`, acento `#c77f0d`, crema `#f7f3ea`;
     tipografías Fraunces (títulos), Inter (texto) y Unica One (`assets/fuentes/UnicaOne-Regular.ttf`, para la marca
     y las URL); logos de `assets/marca/`. Tomar como referencia de estilo `assets/marca/og-imagen.jpg`.
   - Revisar cada imagen antes de enviarla (que nada se superponga ni se salga del borde) y enviarlas como archivos.
2. **El caption listo para copiar y pegar**, dentro de un bloque de código, con emojis, llamado a la acción y hashtags
   (#RadioConexión #ConectadosConTusSentidos #PeriodismoPositivo …).

Datos útiles: Instagram @radioconexionweb · sitio radioconexionweb.com · formulario para participar
radioconexionweb.com/participa. Los datos del post (opciones, pasos, condiciones) deben coincidir con lo que dice el sitio.
